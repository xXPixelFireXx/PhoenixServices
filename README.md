# PhoenixServices
Recoding and Reviving old Google Services to make new, Open Source ones with newer looking aspects.

WE ARE NOT USING THE SAME CODE AS THE ORIGINAL GOOGLE SERVICE, we are simply taking the old code, renovating it, and making it look like a brand new service, all while making it free, open-source, and compatible with any device with a working web browser.

Here is the list of services we are working on so far:

- Play Music/WIP
- Hangouts/Queued Next
- Google+/Last, May take a while.
